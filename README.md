# WhatNext Vision Motors – Salesforce Project

## Project Overview
A Salesforce-based vehicle management and customer experience solution
for WhatNext Vision Motors.

## Features
- Vehicle management
- Vehicle dealer management
- Customer management
- Vehicle order management
- Test drive booking
- Service request management
- Automatic dealer assignment
- Vehicle stock validation
- Test drive reminder email
- Batch Apex for pending orders
- Scheduled Apex processing

## Custom Objects
- Vehicle
- Vehicle Dealer
- Vehicle Customer
- Vehicle Order
- Vehicle Test Drive
- Vehicle Service Request

## Automation
- Auto Assign Dealer Flow
- Test Drive Reminder Flow
- Vehicle Order Trigger
- VehicleOrderTriggerHandler
- PendingOrderBatch
- PendingOrderScheduler

## Technologies
- Salesforce
- Apex
- SOQL
- Lightning Flow
- Custom Objects
